# Changelog

## 0.5.0-beta — 2026-07-13

- Added persistent device settings.
- Added Wi-Fi captive setup and automatic reconnect.
- Added NTP timezone and DST support.
- Added responsive web dashboard and JSON API.
- Added browser-based firmware updates and mDNS.
- Added Open-Meteo weather without an API key.
- Added rotating OLED pages and queued notifications.
- Added button gestures.
- Added five display modes and six themes.
- Added gamma correction, time-based dimming, orientation settings, and current limiting.
- Added HALO logo, icons, documentation, and starter faceplates.

## 0.1.0-alpha

- Verified ESP32-WROOM, SH1106 OLED, and 60-pixel WS2812B hardware.
- Added HALO splash screen and blue LED boot sweep.
