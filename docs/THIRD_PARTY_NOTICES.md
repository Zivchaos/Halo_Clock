## Pikud HaOref alert-area catalog

`webui/red-alert-areas.js` is generated from the `cities.json` catalog in
[eladnava/pikud-haoref-api](https://github.com/eladnava/pikud-haoref-api),
used under the Apache License, Version 2.0. The catalog provides the exact
Hebrew alert-area values used for matching Home Front Command alerts.
