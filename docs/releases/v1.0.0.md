# HALO CST v1.0.0

HALO CST v1.0.0 is the first public release of the Connected Smart Timepiece: a local-first ESP32 clock with a custom LED display engine, responsive embedded WebUI, persistent settings, weather, diagnostics, and OTA support.

## Highlights

- Responsive local WebUI with a live overview, display controls, network configuration, weather, diagnostics, and trusted-LAN safety guidance.
- Runtime LED-ring calibration with persisted 12 o’clock offset, direction, cardinal test, validation, API, and WebUI controls.
- Persisted weather-location configuration with validated WGS84 coordinates and Open-Meteo current conditions.
- CUSTOM display mode with six persisted LED color controls.
- HALO CST visual identity: octagonal marks, favicon, social card, brand guide, and privacy-redacted WebUI captures.

## Validation

- 39 WebUI source checks passed.
- 46 public-release checks passed.
- 38 embedded tests passed: 11 weather, 8 diagnostics, and 19 network-configuration cases.
- ESP32 firmware build passed using the dual-OTA 4 MiB partition layout.

## Known limitations

- The WebUI and ArduinoOTA service are unauthenticated; operate HALO CST only on a trusted LAN and do not expose ports 80 or 3232 to the Internet.
- Hardware enclosure photographs are not yet included. The enclosure remains a maker prototype.
- Release screenshots are representative desktop WebUI views; mobile and physical-prototype imagery can follow in a future release.
